# MVP Requirements

## Purpose

The purpose of the MVP phase is to expand the application into a realistic social networking platform with a broader attack surface.

## Additional Functional Scope

The following functionality shall be added to the PoC implementation.

### User Profiles

* Profile picture uploads

### Social Feed

* Likes
* Profile comments

### Groups

* Group creation
* Group membership
* Public and private groups

### Search

* User search
* Post search
* Group search

### Notifications

* Follow notifications
* Comment notifications
* Like notifications

## Security Objectives

The phase shall provide opportunities to practice:

* File upload vulnerabilities
* Business logic flaws
* Mass assignment
* Broken access control
* Information disclosure

## Exit Criteria

The phase is considered complete when:

* All additional functionality is implemented.
* New planned vulnerabilities are implemented and verified.
* Architecture documentation is updated.
* Security assessment documentation is updated.
