# The Vulnerable Cinephile Social Network Website

## Annotation

This project is designed to help its author — and anyone interested — practice **penetration testing** and **application security** in a realistic web application environment.

The main goal is to build a modern social networking application for cinephiles that is **intentionally vulnerable by design**. The application should provide opportunities to practice exploiting common and realistic weaknesses in web applications, APIs, frontend logic, proxy configuration, and infrastructure.

Both **black-box** and **white-box** penetration testing can be practiced using this project.

The application security part of the project focuses not only on finding vulnerabilities, but also on improving the system over time through secure development practices. This includes secure SDLC standards, policies, procedures, security assessments, and progressive hardening of the application’s security posture.

Each major security improvement should be supported by documentation and reports that demonstrate both technical understanding and the ability to communicate findings in clear natural language.

## Development Phases

The project is divided into the following phases:

1. Planning
2. Creating a vulnerable proof of concept
3. Expanding the PoC into an MVP
4. Security assessment
5. Initial hardening of the security posture
6. OWASP SAMM mapping
7. Final documentation polishing

## Project Purpose

This repository is not intended to represent a secure production application in its early stages. Instead, it intentionally demonstrates how vulnerabilities may appear during software development and how they can later be identified, documented, prioritized, and mitigated.

The long-term goal is to show the evolution of an application from an intentionally vulnerable system into a progressively hardened application guided by application security practices and OWASP SAMM.
